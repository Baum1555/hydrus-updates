# HYDRUS Wassermonitor

Software für den Heltec V3 und Windows-PC zum Empfangen und Auswerten von Funkdaten von HYDRUS-Wasserzählern. Zählerstand, Wasserverbrauch und Durchfluss werden im Browser auf dem Handy oder im PC-Programm angezeigt. Das System speichert Messwerte und warnt bei anhaltendem Wasserfluss oder fehlendem Zählerempfang. Für verschlüsselte Messwerte wird der passende AES-Schlüssel des Wasserversorgers benötigt.
